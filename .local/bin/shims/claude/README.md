# Claude Code 命令行命令的装饰程序

程序 `claude.py` 是 Claude Code 命令行命令的装饰程序．相较于原命令，装饰器增加了一些启动前检查程序，调整了默认选项，列举如下，

- **地理检查**．由于 Claude Code 服务在某些国家或地区不受支持，在启动原命令前，装饰程序将检查当前网络环境所在的地理环境．具体而言，装饰程序将请求 Cloudflare 接口并读取返回值中的国家代码，确保网络出口位于新加坡，否则将报告错误，不再启动原命令．

- **时区设置**．为使时区与网络出口所在地理环境保持一致，装饰程序将为原命令指定新加坡时区．具体实现中，装饰程序将环境变量 `TZ` 设置为 `Asia/Singapore`，覆盖环境已有的值．

- **推理强度**．装饰程序默认以最高推理强度 `max` 启动原命令，除非用户显式指定了推理强度，或以非交互方式启动 Claude Code．

- **设置目录**．在工作区环境下，装饰程序将设置目录修改为工作区子目录 `$ZONE/.config/claude`．其方法是，将环境变量 `CLAUDE_CONFIG_DIR` 设置为目标目录．如果工作区根目录变量 `ZONE` 不存在，则不作设置，回退至默认设置目录．

- **分层设置**．会话中的一些临时修改会产生持久化改动，例如模型选择．为此，装饰程序支持区分不同设置的优先级．其中，`settings.fallback.json` 为尚未设置的选项提供默认值，而 `settings.ironclad.json` 中的设置在每次启动时恢复，不受会话中修改的影响．

完成上述检查与设置后，装饰器在命令搜索目录中查找原命令并执行之．
